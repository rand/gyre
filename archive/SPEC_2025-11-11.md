## 1. API (HTTP, JSON)

### POST /sessions/register
Body:
{
  "session_id": "str",
  "agent_kind": "openai|anthropic|gemini|other",
  "capabilities": ["system_patch","tool_result","realtime","computer_use"],

Body: { "session_id": "...", "events": [ SessionEvent... ] }
- SessionEvent: { "t": "ISO8601", "kind": "user|agent|tool|file|screen", "payload": { ... } }

## 3. Context Patch Protocol (CPP)
Patch {
  id, task_id, target_session_id, ttl_ms,
  slot: task_header|constraints|user_prefs|retrieved_evidence|tool_args|citations,
  body: text or structured payload,
  budget: {max_tokens, max_latency_ms},
  policy: {allowed_scopes:[], sensitivity_max},
  provenance: [citations...]
}

## 4. Selection Objective
Maximize submodular utility under budgets:
J(S) = sum_i u_i - λ * redundancy(i | S\{i})
subject to ∑ tokens_i ≤ B_tokens, ∑ latency_i ≤ B_latency, risk(S) ≤ ρ

u_i = w_r*relevance + w_a*actionability + w_f*freshness + w_imp*importance
      + w_g*graph_centrality - w_c*cost - w_s*sensitivity

Algorithm: Greedy knapsack with MMR diversity; EV-gated execution of deferred queries first.

## 5. DSPy Programs (Signatures)
- ObserveSession(task_desc, events_json) → session_state_json
- ProposePatches(task_desc, session_state_json, neighborhood_json, slot_specs_json) → patches_json
- RankCandidates(task_desc, budget_tokens, items_json, topk) → ranked_ids_json
- SummarizeForSlot(slot_name, max_tokens, items_with_citations_json) → summary_text, kept_citations_json
- EVofDeferredQuery(task_desc, query_plan_json) → ev_score
- RedactForScope(target_scope, draft_json, policy_json) → redacted_json
- BlueprintFill(task_desc, slot_specs_json, fragments_json) → blueprint_json

Metrics & Optimizers:
- RankCandidates: NDCG@k + redundancy/risk penalties; MIPROv2
- SummarizeForSlot: faithfulness via citation overlap + triple checks; MIPROv2
- EVofDeferredQuery: EV↔reward correlation; COPRO
- RedactForScope: zero violations; COPRO
- BlueprintFill: downstream success & cap compliance; MIPROv2

## 6. Governance
- Pre-compose redaction; risk budgets; bitemporal fact validity.
- Audit trail: every patch has provenance and policy verdict.

## 7. Performance Targets
- p95 observe→inject ≤ 600 ms; p99 ≤ 1200 ms.
- Cache canonical slot fragments; delta injection; reserved token headroom.
